01 / OVERVIEW

Why this dashboard exists

The Intelligence Hub turns a dense transformation programme into an explorable story. Six enterprise pillars — Strategy, Technology, Data, Operations, Customer and Innovation — are visualised as nine coordinated charts, each a different lens on the same journey.

◈

9 D3.js charts

Sankey, Sunburst, Circle Packing, Force Network, Treemap, Tangled Tree, Capability Heatmap, Revenue Line Chart, and Maturity Rings — each linked to a shared narrative.

◉

Multi-phase timeline

A 5-year journey (2023–2027). Switch phase via the navigation bar, the timeline strip, or the keyboard arrows ← → — every chart animates to the new phase.

☾

Dark theme

Custom CSS variables drive the palette, an animated grid background adds depth, and ambient glow orbs give the workspace atmosphere.

⛶

Fullscreen mode

Push any card to a floating, immersive viewport with a dedicated control bar. Press Esc to exit.

⌕

Search

Press ⌘K to instantly search 120+ initiatives across all pillars and jump to the matching chart.

⚙

Settings panel

Live-tune the experience: accent colour, animation speed, per-card visibility, and the animated grid toggle.

▤

Card controls

Collapse and expand cards, cycle through heights, export any chart as SVG, and reset zoom with one click.

≋

Layout modes

Rebalance the workspace in Grid, List, or Focus layouts depending on what you are analysing.

⚑

Pillar filtering

Filter the entire workspace by pillar — Strategy, Technology, Data, Operations, Customer, or Innovation — across every chart.

↔

Responsive

A CSS Grid layout that adapts to the viewport — from a dense command-centre wall to a single-column mobile view.

⋯

Context menu

Right-click any chart for quick actions: reset, zoom, export, or fullscreen — no toolbar hunting required.

⇩

Export

Download individual SVGs or all nine charts at once, then drop them straight into a board or report.

04 / USAGE

Getting started

1. Open the dashboard

Launch index.html in any modern browser. No build step required — D3.js v7 is loaded straight from CDN.

2. Explore the phases

Step through 2023 → 2027 using the navigation bar, the timeline strip, or the ← → arrow keys.

3. Dive into any chart

Click nodes to drill down, hover for tooltips, right-click for context actions, and press ⌘K to search across all pillars.
